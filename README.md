
# Simulador de venta de entradas

Proyecto desarrollado para la Pre-Entrega 3 del curso de JavaScript de Coderhouse.

## Descripción
Simulador que permite seleccionar entradas de tipo General, Preferencial o VIP, calcular el total de la compra y mostrar un resumen final.

El proyecto utiliza funciones, parámetros, return, condicionales y ciclos.

## Cómo ejecutarlo
1. Descargar o clonar el repositorio.
2. Abrir el archivo `index.html` en un navegador.
3. Interactuar con el simulador mediante las ventanas emergentes y visualizar los resultados en la consola del navegador (F12).
